# KW1KX Portfolio

Готовая статическая страница в стиле портфолио со скриншотов:
- загрузочный терминал;
- определение ОС, браузера, разрешения экрана и языка;
- переход по клику или Enter;
- адаптивная версия для телефона;
- карточки профиля и ссылок.

## Как поменять аватар

Открой `assets/avatar.svg` и замени его своим изображением, либо:
1. положи рядом файл `avatar.png`;
2. в `index.html` найди `src="assets/avatar.svg"`;
3. замени на `src="assets/avatar.png"`.

## Что поменять под себя

В `index.html`:
- `KW1KX` — имя;
- `Developer / Student`;
- `Identity`, `Location`, `Stack`;
- ссылки Telegram/GitHub;
- текст цитаты.

В `style.css` можно менять цвета через `--accent` и `--accent2`.
